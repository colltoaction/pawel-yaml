# 1. 1968 "Mother of All Demos" with Doug Engelbart & Team (1/3) [re-mastered]

**Speaker**: Doug Engelbart & Team  
**URL**: https://www.youtube.com/watch?v=UhpTiWyVa6k
**Duration**: 34 minutes, 30 seconds  
**Channel**: Doug Engelbart Institute

---

This video demonstrates a sophisticated early computer system designed to augment human intellect. It showcases features like flexible document creation and editing, hierarchical organization, and dynamic view control, all facilitated by innovative input devices. The presentation highlights the system's ability to manage complex information structures and its continuous development through an empirical, self-referential approach.

Here are the key points from the video:

(2:00-2:26) Introduction to the research program for augmenting human intellect, focusing on providing intellectual workers with a responsive computer display.
(2:49-2:57) The presentation aims to show rather than tell about the program's technological products.
(3:01-3:14) The display is a core technological development, allowing for interactive actions like starting with a blank "paper."
(4:04-4:30) Demonstrates basic text operations such as copying words and entities.
(5:44-6:09) Introduces "view control" for constructing customized views of the file, allowing for overviews.
(7:27-7:35) Shows automatic numbering of statements.
(7:42-7:48) The system enables fast work with statement entities in a file.
(8:04-8:15) Demonstrates the ability to revert to a last-saved version of a file.
(9:08-9:20) Shows the ability to reorganize items by moving them.
(10:12-10:25) Demonstrates categorizing items within the shopping list by moving them under a "produce" heading.
(10:44-10:52) Shows moving groups of items under a category.
(11:17-11:29) Explains view control parameters like showing different hierarchy levels (e.g., only two levels deep).
(12:43-13:11) Introduces the ability to jump to a specific location by name or number.
(13:51-14:03) Demonstrates cross-referencing by labeling a section.
(14:47-15:05) Shows linking to a named reference.
(16:37-16:57) Illustrates interchanging categories (e.g., "produce" and "canned materials") and automatic renumbering.

(19:05-19:28) Demonstrates jumping between files using "links" that specify the file, location, and view parameters.
(20:12-20:28) Explains the flexibility in controlling format structures, including character size and spacing.

(24:35-24:45) States the basic goal: improving the effectiveness of individuals and organizations in intellectual tasks.
