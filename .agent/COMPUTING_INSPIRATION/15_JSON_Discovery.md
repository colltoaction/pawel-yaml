# 15. Discovering JSON - Douglas Crockford

**Speaker**: Douglas Crockford  
**URL**: https://www.youtube.com/watch?v=kc8BAR7SHJI
**Duration**: 7 minutes, 8 seconds  
**Channel**: IEEEComputerSociety

---

Douglas Crockford, the creator of JSON, discusses its origin, purpose, and evolution. He highlights that JSON (JavaScript Object Notation) was "discovered" in nature in 2001 and is a language-independent data interchange format. He emphasizes its simplicity compared to XML and explains how it became a standard through a single webpage. Crockford also discusses the decision not to version JSON, ensuring its stability and continued functionality.

Here's a bullet list of key information with timestamps:

Discovery of JSON: Crockford "discovered" JSON in 2001 (0:53) and recognized its value (0:58). He clarifies that he didn't invent it (0:56) as it already existed in nature.
Early Instances and Inevitability: The earliest instance of JavaScript being used as a data interchange format was at Netscape in 1996 (1:15-1:21). Crockford suggests JSON is an "inevitable sort of representation for data" (1:39-1:42).
Language Independence: Although born from JavaScript, JSON was designed to be language-independent (2:00-2:04) and simplified to be the "simplest possible specification for how to structure data" (2:08-2:19).
Becoming a Standard: In 2001, while at State Software developing applications for web browsers (2:27-2:40), Crockford faced resistance due to the prevalence of XML (3:14-3:20). To make JSON a standard, he bought json.org and put up a one-page website (3:41-4:01).
Advantages over XML: The main benefit of JSON is that its data structures are "exactly the same data structures that programming languages represent" (4:47-4:53), making it much easier and faster to use compared to XML (5:06-5:11).
No Version Number: Crockford made the "boldest design decision" (5:34-5:36) not to put a version number on JSON (5:37-5:38), meaning it will never change (5:44-5:45, 6:45-6:47), ensuring its stability as a fundamental infrastructure (5:55-5:57).
