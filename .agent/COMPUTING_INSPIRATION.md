## 🎯 Synergy with Pawel-YAML
These principles guide our implementation:
1. **Guy Steele** → Designing a grammar that grows.
2. **Rich Hickey** → Separating RML theory (simple) from YAML syntax (complex).
3. **Joseph Fisher** → Using GLR (path unwinding) to resolve ambiguities.
4. **UNIX** → Using YACC and Flex as modular building blocks.
